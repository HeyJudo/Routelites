# RouteLite Mobile

Expo React Native mobile app for RouteLite.

## Setup

```powershell
npm install
```

## Run

```powershell
npx expo start
```

The mobile app uses Google Maps for display and Google Places for search. Route optimization must stay in the FastAPI backend.

Map, navigation, and bottom-sheet dependencies are intentionally installed in Phase 2 with Expo-compatible versions.
